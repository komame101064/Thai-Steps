# Thai Steps 表示の決まり

実装は `dist/theme.css`（最後に読み込む）。新しい画面や部品を作るときは、ここの決まりと theme.css の変数を使う。

## 色（1つの色に1つの意味）

| 色 | 変数 | 意味 |
|---|---|---|
| 深緑 | `--t-green` | 基調。ボタン、リンク、タイ語の読み（ローマ字） |
| アイボリー | `--t-bg`・`--t-surface` | 背景とカード |
| 赤 | `--t-red` | 重要・注意・不正解、声調の線 |
| 黄色のマーカー | `--t-mark` | 補足のポイント |
| 真鍮色 | `--t-brass` | 言葉づかい（口語・改まった表現・文語など）と由来の札 |
| 緑の濃淡 | — | 頻度（最高＝濃い緑、高＝薄い緑、中＝白地に緑枠、低＝灰色の枠） |
| 役割・子音の色 | `--c-s` 緑・`--c-v` 橙・`--c-o` 青・`--c-adj` 紫・`--c-tl` 青緑・`--c-fn` 茶 | 文法の課の文の役割、文字の課の子音の種類だけ |

- 文字色は `--t-ink`（見出し）・`--t-text`（本文）・`--t-sub`（補足）の3つ。薄い灰色を直接書かない。
- 本文の文字は背景とのコントラスト比4.5以上。

## 文字の大きさ

見出し1＝22px、見出し2＝17px、見出し3＝15px、本文＝15px、補足＝13px、ラベル＝12px。12px未満は使わない。

## 形

- カード：角丸12px、枠1px（`--t-line`）、内側16〜18px。余白を広げすぎない。
- ボタン：角丸10px、高さ44px、15pxの太字。行の中の小さいボタンは高さ36px・13px。
- 主ボタンは深緑に白文字、副ボタンは白地に緑の文字と枠。

## タイ文字と読み

- タイ文字を上（または左）にやや小さく濃い色で、読みを下（または右）に太字の深緑で。
- 文字の課だけはタイ文字を大きく（字を覚える場所のため）。
- 読みは声調記号付きローマ字。長母音は重ね、ng と書き、音節ごとに空白で区切る。

## 表記

- 文法：第○章・第○課（「STEP」「LESSON」「レッスン」「単元」は使わない）。文字：第○段階・○課。単語：ステップ。
- 単語は「学習済み」、文法・文字の課は「履修済み」。
- 戻るボタン：「← 〇〇一覧に戻る」（単語一覧・フレーズ一覧・文字一覧）、章へは「← 章の名前に戻る」。
- 声調：平声・低声・下声・高声・上声。
- 文の役割：主語・動詞・目的語・形容詞…（SVO などの記号は画面に出さない。「状態」ではなく「形容詞」）。
- 型の区切り：「 + 」でつなぎ、言い換えは「／」。
- 数の表示：「0 / 10」のように斜線の前後に空白。

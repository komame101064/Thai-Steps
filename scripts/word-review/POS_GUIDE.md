# 品詞の見直し（2026-11-26 利用者の指摘「ทำไม が代名詞に分類されてるけど本当？ 他の品詞も見直して」）

日本語話者向けのタイ語学習アプリ。品詞は語義（sense）ごとに1つ。**その語義での働き**で決める。

## 使う品詞（この中から選ぶ）
| 品詞 | 使うもの | 例 |
|---|---|---|
| 名詞 | 物・人・事柄・場所・時を表す名詞（時の名詞 วันนี้・เมื่อวาน もふつう名詞） | บ้าน, เวลา, วันนี้ |
| 代名詞 | 人称代名詞・指示代名詞（単独で「これ・それ」） | ผม, เขา, นี่, นั่น |
| 疑問詞 | 疑問の語（何・誰・どこ・いつ・なぜ・どう・いくつ・いくら・どれ） | อะไร, ใคร, ที่ไหน, เมื่อไร, ทำไม, อย่างไร, ยังไง, กี่, เท่าไร, ไหน |
| 動詞 | 動作・存在・変化 | กิน, ไป, มี, เป็น, อยู่ |
| 助動詞 | 動詞の前後で時制・可能・義務・希望・相を添える語 | จะ, ต้อง, ควร, กำลัง, เคย, ได้（〜できる・〜した の用法）, อยาก（〜したい） |
| 形容詞・状態語 | 性質・状態（述語にもなる） | ดี, สวย, ร้อน |
| 副詞 | 程度・様態・頻度・時の副詞、否定 | มาก, เร็วๆ, บ่อย, ยัง, ไม่, แล้ว（もう〜した）|
| 指示詞 | 名詞の後ろに付く「この・その・あの」 | นี้, นั้น, โน้น |
| 限定詞 | 数量・範囲を限る語（名詞の前） | ทุก, บาง, หลาย, แต่ละ |
| 類別詞 | 数える単位 | คน, ตัว, อัน |
| 数詞 | 数 | หนึ่ง, สอง, ร้อย |
| 前置詞 | 名詞の前で場所・相手・手段など | ใน, กับ, ที่（場所）, จาก |
| 接続詞 | 文・語をつなぐ | และ, แต่, เพราะ, ถ้า |
| 助詞 | 文末助詞・丁寧語・語気 | ครับ, ค่ะ, นะ, สิ, ล่ะ |
| 間投詞 | 感動・応答 | ว้าว, โอ้ย, เออ |
| 接頭辞 | 語を作る前置要素 | นัก-, ความ-, การ- |
| 定型表現 | 2語以上の決まった言い方・あいさつ・フレーズ | ขอบคุณครับ, ไม่เป็นไร |

## 判断のしかた
- 今の品詞が上の基準で明らかに違うものだけ直す。迷うもの・どちらとも言えるものは変えない（理由のない変更はしない）。
- 語義の日本語訳（ja）が示す働きで決める（例：ทำไม「なぜ・どうして」→ 疑問詞、กี่「いくつ」→ 疑問詞、นี้「この」→ 指示詞）。
- 複合語・句（2語以上）でも、1つの語として働くなら その働き（動詞句なら動詞）。決まり文句・あいさつは定型表現のまま。

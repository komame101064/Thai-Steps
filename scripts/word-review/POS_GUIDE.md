# 品詞の基準（第2版 2026-11-26）

利用者の要望：「品詞を徹底的に見直して。タイ語学習に見合うように」。第1版（同日、明らかな誤りだけ直した）を全面的に置き換える。

日本語話者向けのタイ語学習アプリ。品詞は **語義（sense）ごとに1つ**。**タイ語の中でのその語義の働き**で決める。日本語訳の語尾（〜い・〜する）では決めない（例：อยากได้「欲しい」は目的語をとるので動詞、หิว「おなかがすいた」は状態なので形容詞・状態語）。用例文があれば、用例の中での働きを優先する。

## 使える品詞（この17個だけ）
名詞・代名詞・疑問詞・動詞・助動詞・形容詞・状態語・副詞・指示詞・限定詞・類別詞・数詞・前置詞・接続詞・助詞・間投詞・接頭辞・定型表現

## 境界の決め方（ここが本題）

### 1. 動詞 と 形容詞・状態語
- **形容詞・状態語**：性質・状態・感覚・気分を表し、ふつう目的語をとらない。มาก（とても）で程度を言え、名詞の後ろに付いて修飾できる（คนสวย、อาหารเผ็ด）。
  - 体の感覚・体調：หิว・เจ็บ（痛い）・ปวด（痛む）・เหนื่อย・ง่วง・อิ่ม・ไม่สบาย（具合が悪い）・ป่วย（病気だ）・เวียนหัว
  - 気分・感情の状態：ดีใจ・เสียใจ（悲しい）・เหงา・ตื่นเต้น・ประหม่า・งง・เบื่อ（うんざりだ。目的語をとる「〜に飽きる」の語義なら動詞）
  - 色・味・におい・形・大きさ・評価：แดง・เผ็ด・หอม・ใหญ่・ดี
  - 結果の状態：ครบ（そろっている）・เต็ม（いっぱいだ）・หมด（なくなった）など。状態を述べるなら形容詞・状態語。
- **動詞**：動作・出来事・変化・存在・所有・知覚・思考・発話。または **目的語（前置詞なしの名詞）をとる** もの。
  - 感情でも対象をとる語は動詞：ชอบ X・รัก X・กลัว X・เกลียด X・โกรธ X・ห่วง X・คิดถึง X
  - 変化：ตาย・เกิด・โต（成長する）・หาย（治る/なくなる）
- 迷ったら：目的語をとる用法が中心なら動詞。とらず、มากで程度を言うのが中心なら形容詞・状態語。

### 2. 時を表す語
- **名詞**：時点・時期そのもの。前置詞の後ろや主語に置ける。วันนี้・เมื่อวาน・พรุ่งนี้・ตอนนี้（今）・เมื่อกี้（さっき）・ขณะนี้・ช่วงนี้・ตอนเช้า・อดีต（過去）・อนาคต
- **副詞**：動作の様子・頻度・時間の順序・完了・継続を添える。เร็วๆ・บ่อย・เสมอ・ทันที（すぐに）・เดี๋ยวนี้（今すぐ）・แล้ว・ยัง・เพิ่ง（เคย は助動詞）
  - 同じ語でも、「このごろ」のような時期を指す語義は名詞、「すぐに」は副詞。

### 3. 類別詞 と 名詞（単位）
- **類別詞**：数詞の後ろで物・人・出来事を数える語。ตัว・คน・อัน・เล่ม・คัน・ใบ、回数の ครั้ง・ที・หน・รอบ、年齢の ขวบ、倍の เท่า、容器・ひとまとまりで数える แก้ว・ขวด・จาน・ห่อ・อึก（ひと口）・กำมือ（一握り）。
- **名詞**：計量・通貨・時間の長さの単位。กิโลกรัม・กรัม・ลิตร・เมตร・กิโลเมตร・บาท・ดอลลาร์・ชั่วโมง・นาที・วินาที・ปี・เดือน・ไร่・วา・ศอก・โหล（ダース）・เปอร์เซ็นต์。
- 「物」そのものを指す語義（แก้ว＝コップ、ห้อง＝部屋）は名詞。数える語義だけが類別詞。

### 4. 機能語
- **代名詞**：人称（ผม・ฉัน・คุณ・เขา・เธอ・มัน・เรา）、親族名などを「あなた・私」として使う語義（พี่・น้อง・หนู）、単独で「これ・それ・あれ」（นี่・นั่น・โน่น）、อะไร以外の不定代名詞（ใครๆ・ทุกคน）。
- **疑問詞**：疑問の語（อะไร・ใคร・ที่ไหน・เมื่อไร・ทำไม・อย่างไร・ยังไง・กี่・เท่าไร・ไหน・แค่ไหน）。疑問でなく「何でも・誰か」などの不定の語義は代名詞。
- **指示詞**：名詞・類別詞の後ろの「この・その・あの」（นี้・นั้น・โน้น・นู้น）。
- **限定詞**：名詞の前で数量・範囲を限る（ทุก・บาง・หลาย・แต่ละ・ต่าง・อีก（「もう一つの・ほかの」の語義）・เพียง（名詞の前の「たった」））。
- **助動詞**：動詞の前後で時制・可能・義務・希望・相を添える（จะ・ต้อง・ควร・กำลัง・เคย・ได้（可能・過去）・อยาก（〜したい）・น่าจะ・คง・อาจ・ไหว（〜できる・耐えられる、動詞の後ろ））。
- **副詞**：程度（มาก・ค่อนข้าง・นิดหน่อย）、否定（ไม่）、様子、頻度、完了・継続（แล้ว・ยัง・อยู่（進行））、限定（แค่・เท่านั้น）、強調（โคตร・สุดๆ）。「副詞・強調語」は使わず副詞。
- **前置詞**：名詞の前に置き、場所・時・相手・手段・目的を表す（ใน・บน・กับ・จาก・ถึง・ด้วย（手段）・เพื่อ（名詞の前））。
- **接続詞**：節・文・語をつなぐ（และ・แต่・หรือ・เพราะ・ถ้า・ว่า（引用）・ที่（関係節）・จึง・เลย（だから））。後ろに節が来るなら接続詞、名詞が来るなら前置詞。
- **助詞**：文末助詞・丁寧語・語気（ครับ・ค่ะ・นะ・สิ・ล่ะ・เถอะ・หรอก・เลย（強調））、疑問の文末（ไหม・หรือเปล่า・มั้ย）。
- **間投詞**：単独で言う感動・応答の声（โอ้ย・ว้าว・เออ・อ๋อ・ใช่（はい、単独の応答の語義））。
- **接頭辞**：単独では使わず語を作る前置要素（นัก-・ความ-・การ-・ช่าง-・ผู้-・ขี้-）。
- **数詞**：数そのもの（หนึ่ง・สิบ・ร้อย・ครึ่ง）。順序の ที่ + 数（ที่หนึ่ง）は数詞。

### 5. 定型表現
- **定型表現**にする：2語以上でひとまとまりの決まり文句・あいさつ・応答・慣用句・ことわざ（ขอบคุณครับ・ไม่เป็นไร・ได้เลย・อะไรนะ・เป็นไง・สู้ๆ）。1語でも、ある決まった形の中でだけ意味をもつ語義（「〜の形で」と書かれた語義：ไม่เอาน่า の เอา）は定型表現でよい。
- **定型表現にしない**：ふつうの複合語・句で、ひとつの名詞・動詞・形容詞として働くもの（ตู้เย็น＝名詞、ทำงาน＝動詞、ใจดี＝形容詞・状態語、ไม่มี＝動詞）。

### 6. 否定や語を含む句
- ไม่ + 語 の見出し（ไม่มี・ไม่ใช่・ไม่สบาย・ไม่รู้เรื่อง）：全体の働きで決める。ไม่มี・ไม่ใช่・ไม่รู้เรื่อง は動詞、ไม่สบาย（具合が悪い）は形容詞・状態語。
- 「〜すること」「〜な人」など名詞化した語（การ…・ความ…・คน…）は名詞。

## 変えないもの
- `pos-approved.json` に既にある判断（第1版の疑問詞・助動詞・指示詞・限定詞、単位語の名詞）はそのまま。
- 語義の分割・統合はしない。1つの語義に2つの働きが混ざっていると思ったら、品詞は変えず `issue` に書く。
- 日本語訳・用例は直さない（品詞だけ）。訳が品詞と合っていないときは `issue` に書く。

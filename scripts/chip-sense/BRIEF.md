# 用例の「単語に分解」で、各語がどの意味で使われているかを決める

Thai Steps の用例は「単語に分解」で語ごとの意味を表示する。意味が複数ある語は、その文で使われている意味を表示したい。
担当は `scripts/chip-sense/input/<chunk>.jsonl`（1行＝1用例）。各行：`{k, th（タイ語の文）, ja（日本語訳）, toks:[{t（語）, s:[[意味番号, 日本語の意味], …]}]}`。

## 進め方
1. `python3 scripts/chip-sense/next.py <chunk> 40` で、まだ結果のない次の40行を表示する。
2. 各行について、`toks` の**すべての語**に、その文での意味番号を決める。
3. 結果を `scripts/chip-sense/results/<chunk>.jsonl` に、1行につき `{"k":"…","p":{"語":番号,…}}` で追記する（Pythonかヒアドキュメントで `>>`。既存行は書き換えない）。
4. `python3 scripts/chip-sense/check.py <chunk>` で形式を検査し、エラーを直す。1へ戻る。`done` が出たら終了。途中で文脈が要約されても next.py から再開できる。

## 決め方
- 文のタイ語と日本語訳を見て、その語がどの意味で使われているかを選ぶ。番号は `s` の各組の最初の数（並び順ではない）。
- 文法的な使い方に注意する。例：ไป の「行く」と「〜していく（方向・変化）」、ให้ の「あげる」と「〜させる・〜のために」、ได้ の「得る」と「〜できる」と「〜した（過去）」、ที่ の「場所」と「〜する（名詞を説明）」と「〜番目」、อยู่ の「いる」と「〜している」。
- どの意味も合わないときだけ 0 にする（画面ではその語の主な意味を表示する）。
- 他のファイルは編集しない。git・ビルドは実行しない。AIによる判断で、ネイティブ話者の確認ではない。

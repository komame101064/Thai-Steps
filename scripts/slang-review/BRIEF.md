# 口語・スラング欄の精査（ネイティブの使用頻度とカテゴリー）

Thai Steps の「口語・スラング」欄は、日本語話者がタイ人の友達との会話・SNSを理解し使えるようにするための欄です。
利用者から「『よく使う口語』に、本当によく使う語が入っていない（犯罪報道の隠語などが入っている）」と指摘がありました。
あなたは各項目を、**現代のタイ人（特に20〜40代）が日常の会話・SNSで実際にどれくらい使うか**の観点で点検します。

## カテゴリー（category）
- 一般 … 画面名「よく使う口語」。友達との日常会話で**本当によく**聞く・使う口語だけ（例：เว่อร์、ชิล、เซ็ง、ฟิน、แซว、เนียน、ปัง）。頻度7以上が目安。
- 友達の日常 / ほめる・反応 / 気持ち / 誘う・返す / 遊ぶ・飲む / 恋愛・人間関係 / ネット・SNS / 下ネタ / 粗い言葉 / 差別的表現 … 内容で分ける。
- **隠語・報道**（新設）… 犯罪・警察・報道・業界の隠語、日常会話ではまれな俗語（ซ้อม 殴る、อุ้ม 拉致、อม 横領、เก็บ 消す、ผง ヘロイン など）。理解用。
- 意味のカテゴリーと頻度は別：よく使う語でも内容がはっきり「気持ち」「ほめる」ならそちらへ。迷う一般的な口語は「一般」。

## 頻度（frequency 1〜10）
友達との会話・SNSで学習者が出会う頻度。10＝毎日のように聞く（例：ป่ะ・เว่อร์級）、7〜8＝よく聞く、4〜6＝ときどき、1〜3＝まれ・特定の層や文脈だけ。流行が過ぎた語は低めに。

## 出力：results-NN.json（入力と同じ順、全項目）
```json
{"id":"tl-10001","category":"一般","frequency":8,"reason":"日本語で短く（変更した場合は必須）"}
```
- 変えない場合も category と frequency を書く（reason は空でよい）。
- 意味・ローマ字の誤りに気づいたら "issue" に日本語で書く（ここでは直さない）。

## 足りない語の提案：missing-NN.json
このカテゴリー群に**入っていないが、ネイティブが日常で本当によく使う口語・スラング**を最大40語。
`{"th":"…","hint":"日本語の意味","category":"…","why":"なぜよく使うか"}`。
提案前に `grep` で dist/slang-bank*.json と dist/word-bank*.json に同じ綴りがないか確かめ、あるものは出さない。
確信のない語・一時の流行で今は使わない語は出さない。

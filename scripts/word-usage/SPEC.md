# 似た言葉との使い分け（word-usage）

利用者の要望（2026-11-24）：「類義語や近い表現がある場合、使い分けの解説が欲しい」。
単語詳細の「意味と使い方」の下に「似た言葉との使い分け」として表示する。

## 入力
`input-NN.json`：`[{gid, words:[{id, th, ro, f(頻度), pos, ja(語義), style}]}]`。
まとまりは登録済みの類義語・混同しやすい語の関係から機械的に作った候補で、**ずれているものも多い**（例：มัน「それ」と หัวมัน「芋」）。

## 出力 `part-NN.json`（入力と同じ順・同じ gid）
```json
{"gid":"u0001","status":"ok",
 "keep":["tl-…","tl-…"],
 "add":[],
 "lead":"一言で違い（全角60字以内）",
 "items":[{"id":"tl-…","use":"いつ・誰に・どんな場面で使うか（全角50字以内）"}],
 "tip":"迷ったときの目安や間違えやすい点（全角60字以内、なくてもよい）",
 "examples":[{"th":"…","ro":"…","ja":"…"}]}
```
または `{"gid":"…","status":"skip","reason":"日本語で理由"}`。

- `keep`：本当に意味が近く、学習者が使い分けに迷うものだけ（2語以上）。関係の薄い語・別の意味の語は外す。
- `add`：まとまりに欠けている、明らかに比べるべき登録済みの語があれば最大2語まで（`dist/word-bank*.json` に存在する一般語の id）。なければ空配列。
- `items`：`keep`＋`add` の全語、それぞれ1つ。語義の言い換えではなく**違い**（丁寧さ・話し言葉/書き言葉・対象・場面・ニュアンス・文法上の位置）を書く。
- `examples`：0〜2文。比べている語の違いが分かる短い自然なタイ語の文。`th` に比べる語のどれかをそのまま含める。`ro` は `scripts/expansion/ro-lexicon.tsv` の声調付きローマ字の書き方に合わせる（音節ごとに空白）。`ja` は自然な日本語。
- 比べるほどの違いがない・まとまりが成り立たない場合は `skip`。数合わせはしない。
- 文型は「主語・動詞・目的語」など日本語で書く（S/V/O の記号は使わない）。
- AIによる解説で、ネイティブ話者の確認ではない。断定できない点は書かない。

## 検査
`python3 scripts/word-usage/validate.py`（全パート）を実行し、自分の gid のエラーをなくす。

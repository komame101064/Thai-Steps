# 全語の再点検（2回目）：点検担当向け指示

Thai Steps（日本語話者向けタイ語学習アプリ）に登録済みの語を1語ずつ点検し、**おかしいところだけ**直す。
担当は `scripts/audit2/input/<chunk>.jsonl` の全行。結果は `scripts/audit2/results/<chunk>.jsonl` に **1入力行につき1行のJSON** を追記する。

## 進め方
1. `python3 scripts/audit2/next.py <chunk> 40` で、まだ結果のない次の40語を表示する。
2. 40語を判断し、結果をまとめて結果ファイルに追記する（Pythonかヒアドキュメントで `>>` 追記。既存行は書き換えない）。
3. `python3 scripts/audit2/check.py <chunk>` で形式を検査する。エラーは直す。
4. 1へ戻る。next.py が `done` を返したら終了。途中で文脈が要約されても next.py から再開できる。

## 入力（1行1語）
`{id, th, ro, deck(general|slang), style, senses:[{n, ja, pos, note?, ex?:{th, ro, ja}}]}`

## 出力（1行1語）
- 問題なし：`{"id":"tl-00002"}`
- 修正あり：`{"id":"tl-00002","fix":[{"field":"sense.ja","sense":1,"to":"修正後の全文","reason":"日本語で短く"}]}`

`field` は次のどれか（`ro` 以外は `sense` 番号が必須。`to` は置き換え後の**全文**）：
- `ro`：見出し語の読み
- `sense.ja`：語義の日本語訳
- `sense.note`：注釈。**`"to":""` で注釈を削除**
- `ex.th` / `ex.ro` / `ex.ja`：その語義の用例（タイ語文・読み・日本語訳）。`ex.th` を直すときは `ex.ro` と `ex.ja` も合わせて直す。新しい用例は見出し語をそのまま含むこと。

## 何を直すか（明白な誤りだけ。好みの言い換えはしない）
1. **読み（ro, ex.ro）**：声調・母音の長短・子音の明白な誤り、音節の抜け。方式は既存どおり（無印=中平、à低、â下降、á高、ǎ上昇、ɔ ʉ ə ɛ、長母音は重ね字、音節は空白区切り）。確認は `grep -P '^語\t' scripts/expansion/ro-lexicon.tsv`。
   - 決まり：เจ้า=câo、ใต้=tâi、ท่องเที่ยว=thɔ̂ɔng thîiao、โพสต์=phóot、ได้=dâai。**方式の好みの違い・外来語の発音ゆれは直さない。**
2. **日本語訳（sense.ja, ex.ja）**：意味が違う、誤解を招く、不自然な日本語、タイ語にない意味を足している、誤字。
3. **用例（ex.th）**：文法的におかしい、不自然でネイティブが言わない、見出し語がその語義で使われていない。
4. **注釈（sense.note）＝余計な注釈はいらない。** 次のものは**削除**する：訳を言い換えただけ、当たり前のこと、語源や豆知識だけ、言い訳・断り書き（「〜という意味ではありません」等）、他の語の説明、長い解説。
   残すのは学習者の誤用を防ぐものだけ：失礼・粗い・性的などの注意、誰が誰に使うか、決まった形（「〜の形で使う」）、よく使う別の言い方・別表記、紛らわしい語との違い。
   残す場合も**1文・40字程度まで**に短くする（長ければ `to` に短くした文を書く）。スラング（deck=slang）の注釈は使い方の注意が要るので、内容は保ちつつ簡潔にする。
5. 迷うもの・確信のないものは**変えない**。これはAIによる点検で、ネイティブ確認ではない。

## 注意
- 語の追加・削除、語義の追加・削除、品詞や頻度の変更はしない（気づいた重大な問題は `"issue":"…"` に短く書く）。
- 他のファイルは編集しない。git・ビルドは実行しない。

# 使用実態による頻度の見直し（2026-11-27）

利用者の要望：「単語の実際の使用実態を調べて見直して」。範囲は **頻度（1〜10）** と、明らかな場合の **文体の印（口語・文語）**。語義・訳・用例は直さない。

## 頻度の意味
ふつうのタイ人が日常生活で、その語を聞く・言う・読む（会話、SNS、看板、メニュー、ニュース）頻度。画面では 最高（9〜10）・高（7〜8）・中（4〜6）・低（1〜3）の4段階。
- 9〜10：毎日のように使う中心語（上位およそ1,000語）
- 7〜8：よく使う
- 4〜6：ときどき使う・場面が限られる
- 1〜3：まれ・専門・古い・文語のみ

## 手がかり（実測値。どれも判定ではなく材料）
各行に、アプリの 1〜10 の目盛りに合わせた4つの値がある（基本5,000語の頻度で目盛りを合わせたもの。0 は1回も出ない）。
- **subs**：映画・ドラマの字幕（OpenSubtitles、約5,900万語）。会話にいちばん近い。ただし **大半が外国作品の翻訳** なので、
  - 多めに出る：映画らしい語（銃・警察・殺す・宇宙・魔法）、呼びかけ、翻訳調の言い回し。
  - 少なめに出る：タイ固有の語（料理・地名・祭り・タイの制度・タイの物）、方言・くだけた語尾（เนาะ・เงี้ย）、SNS・ネット語。
- **social**：SNSの投稿（約50万語、小さい）。100万語あたりの回数。0でも「使われない」とは言えない。
- **web**：ウェブ全体（Common Crawl）。商品・観光・ニュース・宣伝の語が多めに出る。
- **written**：書きことば（タイ国立コーパス TNC）。新聞・本・公文書。
- 回数は **綴りごと**。同じ綴りの別の語（เค้า「兆し」と口語の เค้า「彼」、ซา と外国人名の一部など）や、1音節の語は数が混ざりやすい。数がその語義から来ていないと思えば無視する。
- 複合語の回数は、文の区切り方によって少なめに出ることがある（下限）。

## 決め方
- 手がかりと自分の知識が **両方とも** 今の値の誤りを示すときだけ変える。迷えば今の値のまま。
- 上げる：会話・日常で明らかによく使う語（例：คิดว่า・แบบนี้・กลับมา・ไม่มีอะไร のような会話の決まった言い方）。
- 下げる：subs・web・written がそろって少なく、日常でも聞かない語（古語・専門語・文語だけの語）。タイ固有の日常語（料理・地名・行事）は subs が0でも下げない。
- 4段階の境目をまたがない小さな変更（5→6 など）はしない。
- 複合語は構成語より高くしない。
- 仲間の語（親族・色・方角・季節・月・曜日・数）は1語だけ動かさない。動かすべきと思ったら `note` に書く。
- 文体の印は、はっきりしている場合だけ：会話ではほぼ言わず書きことばだけ → 文語。くだけた会話でだけ使う → 口語。それ以外は空欄。
